# روزنما (Rooznama) — releases

Persian calendar desktop widget by KomailSoftware.

- **Download:** [latest installer](https://github.com/komailsoftware-cmd/rooznama-releases/releases/latest) (Windows, no admin rights needed).
- `latest.json` is the update feed: installed copies (1.5.2 and later) check it once a day and update themselves silently.
